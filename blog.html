Blog Space

Version-controlled blog for GitHub Pages. Posts are stored as files in this repository.

How To Publish

  1. Create a new file in posts/ (copy an existing post file).
  2. Add metadata entry in data/blog-posts.json.
  3. Commit and push. GitHub Pages deploys automatically.

No local storage dependency. Every post is tracked in Git history.
